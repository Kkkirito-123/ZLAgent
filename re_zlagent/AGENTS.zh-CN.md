# AGENTS.md 中文版本

这是 `AGENTS.md` 的中文配套版本，仅供用户阅读。AI 不应把本文件作为规则输入；工具和 agent 的入口文件仍然是英文 `AGENTS.md`。

## 核心规则

`CLAUDE.md` 是 AI 工作规则和架构边界的英文权威来源，`ROADMAP.md` 是阶段顺序和迁移状态的英文权威来源。

所有 agent 在 `re_zlagent` 内开始工作前，必须先阅读：

```text
AGENTS.md
CLAUDE.md
ROADMAP.md  # 涉及阶段开发或迁移时阅读
```

## 工作边界

- 工作区定位、架构边界、允许改动范围、验证要求，以 `CLAUDE.md` 为准。
- 阶段顺序、进入条件、退出条件和能力决策，以 `ROADMAP.md` 为准。
- 所有 `*.zh-CN.md` 都是用户阅读镜像，不参与 AI 工程决策。
- 如果中文镜像、README、历史注释或旧文档与英文权威文件冲突，优先遵循英文权威文件。
- `re_zlagent/` 外的内容默认只作为参考，除非用户明确批准迁移改动。
- 默认使用中文回复、计划、开发说明和复盘。

## 重要提醒

不要把旧 `backend/` 当作直接复制目标。需要迁移时，应先识别旧能力，再决定保留、替换、延期或移除。
